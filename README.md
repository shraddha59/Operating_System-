# Operating_System-


## 📌 Project Overview

This repository contains C++ programs developed as part of the Operating System (OS).

The project demonstrates important Operating System concepts such as memory management, disk scheduling, page replacement, and IP address allocation using simple and easy-to-understand C++ programs.

## 🎯 Objectives

* To understand fundamental concepts of Operating Systems.
* To implement various OS algorithms using C++.
* To understand memory allocation and page replacement techniques.
* To compare different disk scheduling algorithms.
* To implement IP address allocation and subnet identification.

## 📚 Programs Included

### 1. Disk Scheduling Algorithms

Implementation of the following disk scheduling algorithms:

* FCFS (First Come First Serve)
* SSTF (Shortest Seek Time First)
* SCAN
* C-SCAN

**Purpose:** To calculate total head movement and identify the most efficient disk scheduling algorithm.

### 2. Memory Allocation Algorithms

Implementation of the following memory allocation strategies:

* First Fit
* Best Fit
* Worst Fit

**Purpose:** To allocate memory to processes and calculate remaining free memory and memory utilization.

### 3. Page Replacement Algorithms

Implementation of the following page replacement algorithms:

* FIFO (First In First Out)
* LRU (Least Recently Used)
* Optimal Page Replacement

**Purpose:** To calculate page faults and page hits for different page replacement techniques.

### 4. IP Address Allocation and Subnet Identification

**Purpose:** To validate IP addresses, calculate network addresses using a subnet mask, and identify whether two IP addresses belong to the same subnet or different subnets.

## ▶️ How to Run the Programs

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Operating-System-Assignment.git
```

### Step 2: Open the Project

Open the downloaded folder in Visual Studio Code.

### Step 3: Compile the Program

For example, to compile the disk scheduling program:

```bash
g++ Disk_Scheduling.cpp -o disk
```

### Step 4: Run the Program

```bash

```

For Windows PowerShell:

```powershell
.\disk.exe
```

Follow the same steps to compile and run the other C++ programs.
